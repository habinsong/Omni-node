# Omni-node 사용법

[한국어](./사용법_빠른시작.md) · [English](./en/usage.md)

업데이트 기준: 2026-05-15

이 문서는 대시보드와 텔레그램에서 실제로 자주 쓰는 기능만 묶어 설명한다.

> 텔레그램 봇 슬래시 명령·inline 버튼·음성 첨부·다중 user allowlist 등은 [텔레그램_봇_가이드.md](./텔레그램_봇_가이드.md) 참고.

처음 설치하거나 새 환경에서 실행할 때는 `./scripts/Omni-node setup`을 먼저 실행한다. 이 setup은 의존성 확인/설치, 코어/미들웨어 빌드, `npm test`, 실행기 등록을 처리한다.

## 대화 탭

![대화 탭](./assets/readme/dashboard-chat-tab.png)

대화 탭은 단일 모델, 오케스트레이션, 다중 LLM을 같은 스레드 안에서 바꿔 쓴다. 짧은 일상 대화는 검색과 메모리 주입을 자동으로 줄여 답변 오염을 막고, 최신 정보가 필요한 질문은 Gemini grounding과 evidence guard를 거친다.

브라우저 실행 요청은 대화 입력에서 바로 처리된다. 예를 들어 `네이버 열어줘`, `github.com 열어줘`, `브라우저 닫아줘`처럼 쓰면 LLM 호출 전에 브라우저 intent로 감지하고 실제 Chromium을 연다.

스킬 이름을 직접 말하면 해당 스킬이 활성화되고, 사용자가 중지할 때까지 같은 대화에서 유지된다. 이 흐름은 텔레그램에서도 같다. 미들웨어 재시작 후에도 마지막 활성 스킬이 자동 복원된다.

한 메시지에 스킬 이름이 2개 이상 들어가면 거부 메시지를 받는다 — 하나만 남기고 다시 보내야 한다. UI 드롭다운으로 스킬을 선택해도 프롬프트에서 다른 스킬을 명시하면 프롬프트가 우선한다.

## 코딩 탭

![코딩 탭](./assets/readme/dashboard-coding-tab.png)

코딩 탭은 모델 답변을 파일로 끝내지 않는다. 실행 폴더를 만들고, 파일 생성, 실행 명령, stdout/stderr, 검증 결과, 최근 결과 snapshot을 남긴다.

코딩 탭에서도 `네이버 열어줘` 같은 브라우저 실행 요청은 코딩 작업으로 오인하지 않고 브라우저 intent로 먼저 처리한다.

- 단일 코딩: 한 모델이 끝까지 구현하고 검증한다.
- 오케스트레이션 코딩: 기획, 개발, 검증, 수정 역할을 나눠 진행한다.
- 다중 코딩: 여러 provider/model이 독립 폴더에서 완주하고 결과를 비교한다.

기본 실행 폴더는 `workspace/coding/runs/<timestamp>-<mode>-<suffix>/`다.

## 루틴 탭

![루틴 탭](./assets/readme/dashboard-routines-tab.png)

루틴은 자연어로 만들고, 즉시 실행하거나 예약할 수 있다. 브라우저 에이전트 루틴은 시작 URL, 모델, 도구 프로필을 함께 설정한다. 예약 실행 결과는 루틴별 Telegram 응답 설정에 따라 전송된다.

## 로직 탭

![로직 탭](./assets/readme/dashboard-logic-tab.png)

로직 탭은 `logic.graph.v1` 그래프를 편집하고 실행하는 캔버스다. 대화, 코딩, 루틴, 도구 노드를 연결해 흐름을 만들고, 실행 결과는 `workspace/.runtime/logic/` 아래에 남는다.

## 노트북과 작업 계획

![노트북 탭](./assets/readme/dashboard-notebooks-tab.png)

노트북은 작업 메모, 방향 정리, 검증 내용, 이어보기 문서를 관리한다. 작업 계획 탭은 계획 생성, 리뷰, 승인, 실행, task graph 실행을 담당한다.

![작업 계획 탭](./assets/readme/dashboard-plans-tab.png)

## 스킬과 설정

![스킬 탭](./assets/readme/dashboard-skills-tab.png)

스킬은 `.omni/skills/**/SKILL.md`와 `~/.omninode/skills/**/SKILL.md`에서 읽는다. 설정 탭에서는 인증, 외부접속, LLM 키, provider 상태, routing policy, doctor, 도구 통합 패널을 관리한다. 외부접속 클라이언트는 OTP 없이 제한 모드로 들어오며, 읽기 중심 조회와 모델/라우팅 설정만 허용하고 대화/코딩/루틴/로직 그래프 실행, 인증/시크릿/외부접속 설정은 원격 화면에서 차단된다.

![설정 탭](./assets/readme/dashboard-settings-tab.png)

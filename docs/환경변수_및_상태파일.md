# 환경변수와 상태 파일

[한국어](./환경변수_및_상태파일.md) · [English](./en/environment-and-state.md)

업데이트 기준: 2026-05-21

Omni-node는 설정과 산출물을 섞지 않는다. 설정과 대화 기록은 `~/.omninode`, 실제 작업 결과는 `workspace/`에 둔다.

## 자주 쓰는 환경변수

| 변수 | 의미 |
|---|---|
| `OMNINODE_GEMINI_API_KEY_FILE` | Gemini 키 파일 |
| `OMNINODE_GROQ_API_KEY_FILE` | Groq 키 파일 |
| `OMNINODE_CEREBRAS_API_KEY_FILE` | Cerebras 키 파일 |
| `OMNINODE_NVIDIA_API_KEY_FILE` | NVIDIA NIM 키 파일 |
| `OMNINODE_CODEX_API_KEY_FILE` | Codex API 키 파일 |
| `OMNINODE_WORKSPACE_ROOT` | 코딩 작업공간 루트 override |
| `OMNINODE_GATEWAY_STARTUP_PROBE` | gateway 시작 probe |
| `OMNINODE_ENABLE_LOCAL_OTP_FALLBACK` | 로컬 OTP fallback 사용 여부 |
| `OMNINODE_TELEGRAM_CHAT_ID` | 봇이 응답할 단일 chat_id |
| `OMNINODE_TELEGRAM_ALLOWED_USER_ID` | 허용 user_id (CSV/세미콜론/공백 다중 가능: `"123,456"`) |
| `OMNINODE_NVIDIA_TIMEOUT_SEC` | NVIDIA NIM HTTP timeout (기본 180s) |
| `OMNINODE_CEREBRAS_TIMEOUT_SEC` | Cerebras HTTP timeout (기본 40s) |
| `OMNINODE_NVIDIA_MIN_SINGLE_CHAT_TIMEOUT_SEC` | NVIDIA single-chat 최소 floor (기본 30s) |
| `OMNINODE_CEREBRAS_MIN_SINGLE_CHAT_TIMEOUT_SEC` | Cerebras single-chat 최소 floor (기본 40s) |
| `OMNINODE_SINGLE_CHAT_DEFAULT_TIMEOUT_SEC` | 그 외 provider single-chat 기본 timeout (기본 34s) |
| `OMNINODE_BROWSER_TOOL_MODE` | 도구 패널 browser 어댑터 (`auto` 기본: Playwright 우선, 실패 시 stub fallback / `stub` / `playwright` / `off`) |
| `OMNINODE_BROWSER_HEADLESS` | Playwright browser 어댑터 headless 실행 여부 (`true` 기본, 필요할 때만 override) |

직접 키 문자열을 환경변수에 넣을 수는 있지만, 운영에서는 `*_FILE` 또는 secure store 사용을 권장한다.

## 상태 위치

| 위치 | 내용 |
|---|---|
| `~/.omninode/conversations.json` | 대화 기록 (`ConversationThread.ActiveSkillName`으로 활성 스킬 영구화) |
| `~/.omninode/plans` | 계획 원본 |
| `~/.omninode/tasks` | task graph 원본 |
| `~/.omninode/notebooks` | 노트북과 handoff 문서 |
| `~/.omninode/routing-policy.json` | provider fallback 정책 |
| `~/.omninode/llm_usage.json` | Groq/Gemini 사용량과 rate limit 상태 |
| `~/.omninode/copilot_usage.json` | Copilot 모델 선택과 로컬 사용량 상태 |
| `~/.omninode/guard_retry_timeline.json` | guard retry timeline 상태 |
| `~/.omninode/skill_aliases.json` | `/skill quick` 단축 별명 매핑 (key=별명 lowercase, value=스킬 이름) |
| `workspace/coding/runs` | 코딩 실행 산출물 |
| `workspace/coding/routines` | 루틴 실행 결과 |
| `workspace/.runtime/logic` | 로직 그래프 실행 로그 |
| `workspace/.runtime/tasks` | task graph 실행 로그 |
| `workspace/.runtime/refactor-preview` | Safe Refactor preview |

## 상태 저장소 인벤토리

JSON 상태 저장소는 가능한 경우 `AtomicFileStore`를 통해 파일별 `.lock` lease를 잡고 원자 교체한다. 기존 정상 파일은 같은 경로의 `.bak`로 남는다. 아래 표의 “원자 쓰기 + 백업 복구”는 primary JSON이 손상됐을 때 `.bak`를 검증하고 primary를 복구하는 읽기 경로까지 있다는 뜻이다.

| 상태 | 기본 위치 | override | 처리 기준 |
|---|---|---|---|
| 대화/스킬 활성 상태 | `~/.omninode/conversations.json` | `OMNINODE_CONVERSATION_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 인증 세션 | `~/.omninode/auth_sessions.json` | `OMNINODE_AUTH_SESSION_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 루틴 정의 | `~/.omninode/routines.json` | `OMNINODE_ROUTINE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| LLM 사용량 | `~/.omninode/llm_usage.json` | `OMNINODE_LLM_USAGE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| Copilot 사용량 | `~/.omninode/copilot_usage.json` | `OMNINODE_COPILOT_USAGE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 라우팅 정책 override | `~/.omninode/routing-policy.json` | 없음 | 원자 쓰기 + 백업 복구 |
| 계획 index/본문/리뷰/실행 기록 | `~/.omninode/plans/index.json`, `~/.omninode/plans/<planId>/*.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Task graph index/본문 | `~/.omninode/tasks/index.json`, `~/.omninode/tasks/<graphId>.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Telegram reply outbox | `~/.omninode/telegram_reply_outbox.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Guard retry timeline | `~/.omninode/guard_retry_timeline.json` | `OMNINODE_GUARD_RETRY_TIMELINE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| Gateway health snapshot | `~/.omninode/gateway_health.json` | `OMNINODE_GATEWAY_HEALTH_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| Gateway startup probe snapshot | `~/.omninode/gateway_startup_probe.json` | `OMNINODE_GATEWAY_STARTUP_PROBE_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| 외부접속 설정 | `~/.omninode/dashboard_access.json` | `OMNINODE_DASHBOARD_ACCESS_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| Doctor 마지막 결과/히스토리 | `~/.omninode/doctor/last-report.json`, `~/.omninode/doctor/history/*.json` | 없음 | 원자 쓰기, 읽기 복구 없음 |
| Safe Refactor preview | `workspace/.runtime/refactor-preview/*.json` | 없음 | 원자 쓰기, TTL 기반 임시 상태 |
| Logic graph 실행 snapshot | `workspace/.runtime/logic/<graphId>/<runId>/snapshot.json` | 없음 | 실행 산출물, 읽기 복구 없음 |
| Task graph 실행 stdout/stderr/result | `workspace/.runtime/tasks/<graphId>/<taskId>/` | 없음 | 실행 산출물, 읽기 복구 없음 |
| 노트북 문서 | `~/.omninode/notebooks/<projectKey>/*.md` | 없음 | 원자 쓰기, Markdown 문서 |
| 메모리 노트 | `~/.omninode/memory-notes/*.md` | `OMNINODE_MEMORY_NOTES_DIR` | 원자 쓰기, Markdown 문서 |

`doctor --json`의 `workspace` 체크는 상태 루트의 JSON, `.bak`, `.lock`, 손상 JSON 개수를 보고한다. 손상 JSON이 있으면 `corruptJsonFiles=상대경로:backup=yes|no` 형식으로 백업 존재 여부도 함께 노출한다.

## 키 파일 예시

```bash
mkdir -p "$HOME/.omninode/keys"
printf 'YOUR_GROQ_KEY' > "$HOME/.omninode/keys/groq_api_key"
chmod 600 "$HOME/.omninode/keys/groq_api_key"
export OMNINODE_GROQ_API_KEY_FILE="$HOME/.omninode/keys/groq_api_key"
```

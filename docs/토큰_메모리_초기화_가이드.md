# 토큰 / 메모리 초기화

[한국어](./토큰_메모리_초기화_가이드.md) · [English](./en/token-memory-reset.md)

업데이트 기준: 2026-05-08

Omni-node는 최근 대화, 메모리 노트, 검색 결과를 필요한 경우에만 문맥으로 붙인다. 답변이 이상하게 과거 문맥에 끌려가면 먼저 메모리 연결 상태를 확인한다.

## 대시보드에서 초기화

- 대화/코딩 작업함 하단의 `메모리 초기화` 버튼을 사용한다.
- 특정 대화만 정리할지, scope 전체를 정리할지 확인한다.
- 초기화 후 새 질문으로 다시 테스트한다.

## 텔레그램에서 초기화

```text
/memory clear
메모리 초기화해줘
```

## 판단 기준

- 짧은 인사나 단순 수식에는 검색/메모리를 붙이지 않는 것이 정상이다.
- 최신 정보 질문은 검색 evidence가 붙을 수 있다.
- 프로젝트 코드 질문은 AGENTS와 필요한 파일 문맥이 우선이다.

# 검증 가이드

[한국어](./검증_가이드.md) · [English](./en/validation.md)

기능을 바꿨다면 최소한 아래 순서로 확인한다.

## 기본 검증

| 명령 | 기대 결과 |
|---|---|
| `make -C apps/omninode-core` | 코어 빌드 성공 |
| `python3 apps/omninode-sandbox/executor.py --code "print('ok')"` | `ok` 출력 |
| `dotnet build apps/omninode-middleware/OmniNode.Middleware.csproj` | 미들웨어 빌드 성공 |
| `npm test` | 저장소 위생, 보안 경계, 화면/계약 테스트 통과 |
| `./scripts/Omni-node setup` | macOS/Linux 의존성 확인/설치, 빌드, 검증, 실행기 등록 |
| `curl -s http://127.0.0.1:8080/readyz` | 준비 상태 확인 |
| `dotnet run --project apps/omninode-middleware/OmniNode.Middleware.csproj -- doctor --json` | doctor JSON 출력 |

Windows 코어 빌드는 아래를 쓴다.

```powershell
.\scripts\Omni-node.ps1 setup
.\apps\omninode-core\build.ps1
```

## 수동 회귀 체크

- 대화 탭: 단일/오케스트레이션/다중 LLM 전환
- 코딩 탭: 실행 폴더 생성, 최근 결과 복원, 프리뷰 열기
- 루틴 탭: 즉시 실행, 예약 상태, Telegram 전송 여부
- 로직 탭: 그래프 저장, 실행, 산출물 생성
- 노트북: 기록 저장과 handoff 생성
- 설정: 외부접속 토글, 민감 설정 차단, provider 상태
- 보안 경계: 미인증 WebSocket 요청 거부, 외부접속 제한 모드 자동 진입, 외부 OTP 요청 차단, 외부 인증/시크릿/외부접속 설정 차단 메시지 구분, 외부 대화/코딩/루틴/로직 그래프 실행 차단, 외부 읽기 중심 조회와 모델/라우팅 설정 허용, WebSocket Origin 검사, 루틴 이미지 프리뷰 경로 제한, 첨부 개수/크기 초과 reject, Markdown raw HTML 차단

# 디렉터리 가이드

[한국어](./디렉터리_가이드.md) · [English](./en/directory-guide.md)

업데이트 기준: 2026-05-15

현재 canonical 레이아웃은 `apps/`, `docs/`, `workspace/`다. 루트의 예전 alias 경로가 보이더라도 새 코드는 canonical 경로에 둔다.

## 루트

| 경로 | 설명 |
|---|---|
| `apps/omninode-core/` | C 코어 데몬 |
| `apps/omninode-middleware/` | .NET 미들웨어, WebSocket/HTTP, 텔레그램, 라우팅 |
| `apps/omninode-dashboard/` | 정적 웹 대시보드 |
| `apps/omninode-sandbox/` | Python 실행기 |
| `docs/` | 한국어 문서와 `docs/en/` 영어 문서 |
| `docs/assets/readme/` | README와 기능 문서용 PNG 13개 |
| `workspace/` | 작업 산출물 |
| `scripts/` | setup/start/shutdown/test 스크립트 |
| `deploy/` | systemd/launchd 템플릿 |

## 작업 산출물

| 경로 | 내용 |
|---|---|
| `workspace/coding/runs/` | 코딩 탭 실행별 폴더 |
| `workspace/coding/routines/` | 루틴 실행 결과와 브라우저 에이전트 자산 |
| `workspace/.runtime/logic/` | 로직 그래프 실행 로그 |
| `workspace/.runtime/tasks/` | task graph 실행 로그 |
| `workspace/.runtime/refactor-preview/` | Safe Refactor preview |

## 보존 기준

`~/.omninode`는 영속 상태 원본이다. 대화, 계획, 노트북, 라우팅 정책, 세션 정보가 들어 있으므로 삭제 전에는 반드시 보존 여부를 확인한다.

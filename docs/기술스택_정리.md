# 기술 스택

[한국어](./기술스택_정리.md) · [English](./en/tech-stack.md)

업데이트 기준: 2026-05-21

Omni-node는 하나의 거대한 프레임워크가 아니라 역할별로 작은 런타임을 나눠 붙인 구조다.

| 영역 | 기술 | 이유 |
|---|---|---|
| 코어 | C11 | 단일 인스턴스, 로컬 IPC, 작은 실행 파일 |
| 미들웨어 | .NET 9 | WebSocket/HTTP, 텔레그램, 파일 상태, provider 라우팅 |
| 대시보드 | HTML/CSS/JavaScript | 별도 번들러 없이 정적 파일로 배포 |
| 실행기 | Python | 간단한 코드 실행과 검증 |
| 테스트 | Node.js, npm scripts | 저장소 위생, WebSocket 계약, 프런트 문법 확인 |
| 상태 | JSON, Markdown, SQLite 일부 | 사람이 읽을 수 있는 운영 상태와 기록 |

## LLM 연동

- Gemini: API와 grounding 검색
- Groq: OpenAI 호환 HTTP
- Cerebras: HTTP API
- NVIDIA NIM: OpenAI 호환 chat completions
- Copilot: CLI 래퍼
- Codex: CLI/API 경로

## 프런트엔드 원칙

대시보드는 도구형 화면이다. 정보 밀도, 반복 사용, 모바일 입력 UX를 우선한다. landing page처럼 꾸미기보다 대화, 실행 결과, 설정, 로그가 빠르게 보이도록 구성한다.

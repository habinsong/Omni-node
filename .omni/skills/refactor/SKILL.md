---
name: refactor
description: 코드의 실제 동작을 변경하지 않으면서 구조와 가독성을 개선합니다.
---

리팩터링을 수행할 때는 다음을 지킵니다:
1. **행동 유지**: 기존의 비즈니스 로직이나 외부로 노출되는 동작은 절대 변경하지 않습니다. 새로운 기능을 추가해서도 안 됩니다.
2. **중복 제거 (DRY)**: 반복되는 코드는 헬퍼 함수나 상수로 분리합니다.
3. **의도 명확화**: 불명확한 조건문, 깊게 중첩된 if문, 복잡한 삼항 연산자를 조기 반환(Early return) 등을 통해 읽기 쉽게 풀어냅니다.

코드를 수정한 뒤, 어떤 이유로 구조를 변경했는지(Trade-off) 1~2줄로 간략히 요약해 주세요.

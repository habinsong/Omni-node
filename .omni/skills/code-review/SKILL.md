name: code-review
description: 현재 코드의 복잡도, 가독성, 잠재적 버그를 리뷰합니다.
---

코드 리뷰를 수행할 때는 다음 기준을 따릅니다:
1. **가독성**: 변수명과 함수명이 명확한가? 의도를 알 수 없는 매직 넘버나 하드코딩된 값이 없는가?
2. **복잡도**: 함수가 너무 길거나 한 함수가 여러 가지 책임을 가지고 있지 않은가?
3. **안전성**: 예외 처리 누락, 널(Null) 참조 등 잠재적 버그가 없는가?

결과를 마크다운 목록 형태로 짧고 명확하게 제시하고, 비판만 하는 대신 수정이 필요한 부분은 개선된 코드 스니펫을 반드시 함께 제공하세요.

---
name: write-tests
description: 지정된 함수나 컴포넌트에 대한 단위 테스트(Unit Test) 코드를 작성합니다.
---

단위 테스트 코드를 작성할 때는 다음 원칙을 엄격히 지킵니다:
1. **커버리지**: 정상 경로(Happy path)뿐만 아니라 경계값(Edge cases)과 예외 상황(Sad path)을 모두 포함합니다.
2. **구조**: 테스트 코드는 `AAA (Arrange, Act, Assert)` 또는 `Given, When, Then` 패턴을 명확히 따릅니다.
3. **명명 규칙**: 테스트 함수 이름은 '어떤 상황에서', '어떤 동작을 할 때', '어떤 결과가 나와야 하는지' 명확하게 읽히도록 작성합니다.

작성 전 기존 프로젝트에 사용된 테스트 프레임워크(Jest, xUnit, pytest 등)를 먼저 확인하고 그 스타일에 맞춥니다.
